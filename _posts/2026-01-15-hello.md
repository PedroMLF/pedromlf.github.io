This is an example post. To add a new one, drop a Markdown file in the
`_posts/` folder named with the date and a slug:

```
_posts/2026-03-20-my-new-post.md
```

Start each file with a small block of front matter:

```yaml
---
layout: post
title: "My new post"
description: "One line shown in the blog list (optional)."
---
```

Then write in plain Markdown below it. Headings, **bold**, [links](https://example.com),
lists, and code blocks all work. Commit, push, and it appears in a minute or two.

You can delete this file whenever you like.
